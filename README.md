📊 FinTech Revenue & Transaction Analytics Using SQL
📌 Project Overview

This project analyzes 60 FinTech transactions using MySQL to identify revenue trends, customer behavior, payment-method performance, and transaction success rates.

The analysis uses SQL to generate meaningful financial KPIs and business insights.

🎯 Key Objectives
Analyze monthly revenue trends
Calculate month-over-month revenue growth
Identify top customers by revenue
Analyze revenue by payment method and transaction type
Calculate transaction success and failure rates
Calculate cumulative revenue
Identify high-value transactions
🛠️ Tools & Technologies
MySQL
MySQL Workbench
SQL
Microsoft Excel
🧠 SQL Concepts Used

GROUP BY • ORDER BY • CASE • CTEs • Subqueries • LAG() • RANK() • Window Functions • Aggregate Functions
